# DataMaster 元数据能力

## 能力边界

- 通过数据源、资产、字段和血缘能力识别可问数的数据表。
- 表级 Skill 必须基于真实资产、真实字段和真实数据源生成。
- 字段缺少注释或业务说明时，必须标记为待确认。

## 关键上下文

- 数据源名称、类型、连接库名用于判断 SQL 方言和表定位。
- 表名、表注释、资产描述用于判断业务主题。
- 字段名、字段类型、字段注释、主键、可空标记用于生成字段说明。
- 血缘和关联表信息可用于补充关联关系，但不能编造不存在的 JOIN 条件。

## 表级 Skill 生成规则

- 只描述当前表和已知字段，不扩展未采集到的结构。
- 将时间字段、指标字段、维度字段分开描述。
- 对缺注释字段、敏感字段、可空字段给出注意事项。
- 示例问题必须围绕当前表可回答的问题生成。
