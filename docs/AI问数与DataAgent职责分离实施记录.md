# AI 问数与 Data Agent 职责分离实施记录

## 最终入口

- **Data Agent 悬浮窗**：平台流程建设，含接入、探查、资产、本体、动作和指标候选预览/确认保存草稿。不承接日常指标查询，不提供指标分析或DB-GPT工具。
- **现有 AI 问数页面**：统一问答、正式指标分析、探索问数、报告和保存个人分析条件。不是另建聊天页。
- **本体指标管理**：人工完善口径、校验、发布、版本和停用。流程生成只保存DRAFT，不自动发布。

## 接线

前端 `datamaster-ui/src/views/ai/chat/index/index.vue` 改用：

`POST /ai/ask-data/chat/stream`

新增本体选择；正式指标不要求预选DB-GPT数据源。探索问数/报告仍要求选数据源。普通会话继续使用ASK_DATA及原消息保存API。

后端 `AiAskUnifiedController`：

1. 在请求线程校验真实用户、空间成员、普通ASK_DATA会话、本体及可选数据源归属。
2. 按原始question规则分流；管理或指标草稿生成请求提示前往Data Agent，混合问题先澄清。
3. METRIC运行独立 `AskMetricAgentService`，不调用DataAgent运行时，仅提供8个分析工具。
4. EXPLORATORY普通问答复用原DB-GPT流；报告模式复用原generateReport，不因“报告”一词绕过正式指标分流。

指标路径使用LangChain4j原生工具循环、24消息记忆窗口、每次最多12次工具调用。记忆命名空间含用户/空间/本体/普通会话；操作ID为ASK_METRIC_UUID，保存确认绑定用户、空间、会话和本体。

METRIC的SSE为公开活动steps、最终result(AgentRunResponse JSON)、done；不是逐token流。探索报告额外report事件；普通DB-GPT原有message/sql/steps/error事件继续处理。前端显示真实结果表、解释、截断警告、待保存完整参数及确认按钮；切换空间或会话会放弃旧请求。声明式图表配置只提示已生成，未新增渲染器。

## 流程侧指标建设

新增 `preview_metrics` 与 `save_metric_draft`，通过现有@AgentTool目录自动注册为管理工具；不暴露给问数运行时。

- 预览基于当前本体、真实概念/属性/表列映射，以及已有Doris ADS绑定元数据。
- 可传结构化候选建议，或保守生成最多5项COUNT(*)/数值SUM候选；未知粒度标unknown，口径标待业务确认。
- 不查Doris、不创建表或绑定、不生成SQL、不发布指标。命名检查不是查询授权。
- 候选previewDigest与元数据指纹持久化在原操作结果中，保存只接受预览索引和digest，不接受任意指标定义。
- 首次保存返回NEED_CONFIRMATION。确认后运行时从最后持久化pending恢复参数，直接调用工具，不要求模型重抽口径或重复查询。
- 保存与确认消费在操作行锁事务中执行，并重新核对实际元数据。指标写入ont_metric，status=DRAFT、publishedVersion=0。正式发布仍走本体管理。
- 当前概念上下文不足时会要求提供/选择本体概念，未新增概念检索Tool或自动创建绑定，不能宣称一句话能覆盖所有元数据准备。

## 持久化

- 指标草稿：ont_metric；发布快照：ont_metric_version。
- 个人分析条件：ont_metric_analysis。
- 问数会话和消息仍使用现有AI会话管理，操作、审计和加密记忆仍落现有AI相关表。
- 分析条件表不存结果不代表全平台不存结果：操作/审计/记忆及普通问数消息可能包含查询返回数据。见数据分析Agent实施方案的入库边界。

没有新增本次专用数据库迁移；仍需先人工执行前两批指标迁移，之后配置权限、只读账号和受控查询开关。没有修改application环境配置，也没有实际访问Doris或模型服务。

## 验证状态与限制

- 代码已合入工作区，未运行编译、构建、lint、测试、迁移或实际端到端联调。
- 新增MetricDraftToolsTest，覆盖候选、摘要、确认和元数据验证；测试未执行。
- 问数页本体选择目前为页面状态，不写入原会话结构；刷新后需重新选择，保存确认仍使用原消息绑定的本体。
- 新运行时取消检查可阻止后续工具和迟到结果，不能保证中断已经在途的模型HTTP、Doris查询或保存事务。
- 新问数运行锁为单JVM会话锁，多实例普通查询仍需分布式并发治理。
- 原DB-GPT流式实现仍累计上游回复后发送，原steps可能包含供应方thought字段、错误可能有供应方细节，原取消/超时行为未重构。这是遗留限制，不能宣称全路径已统一安全流式化。
- 规则意图识别仍需真实语料验证；指标正式执行默认关闭，不允许自动回退自由SQL来绕过口径。

## 人工验收重点

1. DataAgent只能建设流程；“生成指标草稿”预览后确认保存，不能自动发布。
2. 问数页选择本体：指标口径/查询/比较/排名均使用正式工具，不触发创建资源。
3. 不选择本体的指标问题明确要求选择；探索问题使用授权数据源，正式指标失败不回退DB-GPT。
4. 原报告模板、表格、普通会话历史可用；新result/report事件不重复或覆盖结构化展示。
5. 保存分析完整参数先展示，确认后不重新调用模型/SQL，同operation不能重复保存。
6. 非成员、跨会话、跨本体、DataAgent操作ID作为问数确认ID均拒绝。
7. Java8与LangChain4j Schema验证、前端生产构建、Doris基准对账和真实流式联调由用户在本地执行。
