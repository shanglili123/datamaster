# 指标—分析—决策全流程优化实施方案

## 后续优先级与产品原则（2026-11-10补充确认）

后续统一以根README第1.1/1.2节和 [平台增强清单与实施优先级](平台增强清单与实施优先级.md) 为准：**空间流程配置与执行第一，分析增强第二，质量闭环第三，其余最后**。空间未配置时可按项目回退元数据；配置资产/质量后严格执行，不得回退绕过。质量达标或有权限的人明确确认可用都可成为准入依据，原检查结果与人工确认分开保留。ODS/DWD/DWS/ADS及业务分类属于人工约定，不建设必经分层门禁。现有负责人复用，不重复建设。

本文是此前专题代码记录，标记代码完成不代表已完成新的空间功能流程，也不代表正式指标已解除当前Doris ADS/严格资产来源限制；上述仍需按新规则逐项改造和验收。

## 目标与完成标准

把现有受控能力串成可恢复、可解释、显式确认的业务流程：

目标与范围 → 条件补充 → 正式指标证据 → 候选比较 → 处置/不干预/暂缓 → 执行影响核对 → 原审批执行 → 观察窗口 → 效果复查。

完成标准是本方案范围的前后端、迁移、回归测试代码及交付说明齐备；不把未运行的测试、未执行的迁移或未做的现场联调说成通过。不运行构建、测试、lint、服务启动、迁移、模型调用或真实动作；不提交Git。

## 安全及产品边界

- 保留正式指标/探索、管理/使用、模型建议/人工执行之间的边界。
- 所有写入口校验原所有者、空间、本体、revision；修改后旧预览失效；提交沿用稳定幂等键和既有审批。
- 不自动审批/执行/重试副作用，不执行模型生成的SQL，不将外部函数/Webhook当作可安全试跑。
- 口径严格匹配继续作为默认。跨概念可比性需要管理员维护的版本化规则；本轮不靠模型猜等价，也不以人工“确认一致”绕过。
- 效果复查只给同口径的观测变化/目标达成，不将前后变化宣称为干预因果收益。

### 已实现位置与协议

- 会话：`AiAskSessionSaveReqVO` / `AiAskSessionRespVO` / `AiAskSessionDO` 增加 ontologyId；`AiAskSessionServiceImpl` 校验成员和同空间本体，wrapper显式SET null。已有表不再运行时自动补列或回填category；旧部署必须人工迁移。
- 页面：会话恢复在异步请求前设定ontology/null；配置保存串行并带上下文守卫；本体、数据源、模式、空间、会话变化作废旧请求，Skills/模板/会话列表迟到响应不得覆盖新上下文。
- 分析转决策：`analysisOperationId` 只能引用同用户/空间/本体/会话中SUCCEEDED且有正式查询工具的服务器操作，合并服务端原目标后重新查询。不复制客户端结果行，不代表原分析数据仍新鲜。
- 任务列表：`GET /ai/decision/tasks` 当前用户/空间最新50个任务，刷新时查询原执行流程对账，返回有限摘要，不复制完整证据；恢复详情不重新执行。
- 人工处置：`POST /ai/decision/disposition` 支持 ACCEPT_NO_ACTION / DEFER / ABANDON / REOPEN，原因必填，暂缓须未来复查时间。与prepare/confirm共用revision与首行mutex；无dispatch的新版本才能处置，不取消已提交动作。
- 有效期：新提案草稿7天，证据30分钟，预览不超过30分钟及剩余证据时效。重新打开不延长证据；过期证据可复制目标重新分析。旧提案缺新字段按原expiresAt保守解释。
- 测算：继续用严格同口径规则；绑定改变后保留输入而清除结果/排名/预览、关闭数量同步；有保留输入却无结果时必须重算。业务投入与执行参数映射分区展示，标识标准成本—产能模板。
- 影响预览：`IActionExecutionService.previewImpact` 是独立SELECT-only路径，不复用原DML dry-run（原路径实际executeUpdate后rollback）。匹配数最多1000，最多读1001条常量行，JDBC超时5秒，不读行内容。CREATE仅报告计划插入1行；函数/Webhook/复合动作/Workflow/无界对象解析等返回UNKNOWN。结果纳入提案摘要并在confirm及dispatch前复查；UNKNOWN或截断需单独明确知悉。
- 观察计划：`POST /ai/decision/effect-plan` 在提交前选择真实单值正式指标基线，冻结版本/过滤和未来观察窗口；要求两窗口等长、不含额外时间过滤，方向INCREASE/DECREASE、非负绝对变化阈值、带offset的预计就绪时间。保存计划作废旧预览。
- 效果复查：`POST /ai/decision/{id}/review` 仅执行成功后；未到readyAt返回WAITING_OBSERVATION，实际完成时间缺失/晚于观察开始为INCONCLUSIVE。查询沿用原版本与过滤，仅改观察日期，重新授权；保存基线、观测、差值、方向、阈值、执行时间。正向变化且达到阈值为IMPROVED，零变化不因阈值0冒充改善；空值/截断/失权不当零。结果标记dataFreshnessVerified=false，不作因果收益归因。
- UI：可从分析消息制定方案；可从当前空间任务列表恢复；不干预/暂缓/放弃可归档；提供原审批入口，运行状态最多6次、15秒间隔有限刷新，隐藏/卸载/禁用停止，不自动续跑。效果计划与观测在决策卡片展示。
