# 数据开发当前实现说明

## 结论

当前项目里的“数据开发”复用 collector 模块的 ETL 任务体系，不单独维护一套后台。

数据开发通过 `type = "3"` 和数据集成任务区分；数据集成离线任务通常是 `type = "1"`。两者共用 `/col/etlTask` 接口、任务表、节点表、发布逻辑、调度逻辑和 DolphinScheduler 对接能力。

一句话概括：

> 数据开发 = 数据集成/ETL 任务后台 + `type=3` + SQL/Shell/存储过程/Python 组件 + DolphinScheduler 执行调度。

## 前端入口

数据开发前端页面主要在：

- `datamaster-ui/src/views/col/task/developTask/index.vue`
- `datamaster-ui/src/views/col/task/developTask/add/add.vue`
- `datamaster-ui/src/views/col/task/developTask/detail/index.vue`

数据集成前端页面主要在：

- `datamaster-ui/src/views/col/task/integratioTask/index.vue`
- `datamaster-ui/src/views/col/task/integratioTask/edit/index.vue`
- `datamaster-ui/src/views/col/task/integratioTask/detail/index.vue`

数据开发列表查询和新增任务时通过 `type = "3"` 区分任务类型。

## 后台入口

数据开发后台复用数据集成任务 Controller：

- `datamaster-collector/datamaster-collector-biz/src/main/java/com/datamaster/module/collector/controller/admin/etl/CollectorEtlTaskController.java`

核心 Service 实现在：

- `datamaster-collector/datamaster-collector-biz/src/main/java/com/datamaster/module/collector/service/etl/impl/CollectorEtlTaskServiceImpl.java`

## 任务类型

任务类型枚举在：

- `datamaster-common/datamaster-common-common/src/main/java/com/datamaster/common/enums/TaskCatEnum.java`

当前定义：

```java
TAX_TASK_CAT("1", "离线数据集成任务"),
CAT("2", "实时任务"),
TAX_DATA_DEV_CAT("3", "数据开发任务"),
TAX_JOB_CAT("4", "作业任务");
```

所以数据开发的后台标识是：

```text
type = 3
```

## 组件类型

组件类型枚举在：

- `datamaster-common/datamaster-common-common/src/main/java/com/datamaster/common/enums/TaskComponentTypeEnum.java`

其中数据开发相关组件包括：

```java
SQL_DEV("51", "SQL开发"),
PROCEDURE_DEV("52", "存储过程开发"),
SHELL_DEV("54", "SHELL开发"),
PYTHON_DEV("56", "Python开发");
```

对应的后端组件转换类在：

- `datamaster-collector/datamaster-collector-biz/src/main/java/com/datamaster/module/collector/utils/ds/component/SQLComponent.java`
- `datamaster-collector/datamaster-collector-biz/src/main/java/com/datamaster/module/collector/utils/ds/component/ProcedureComponent.java`
- `datamaster-collector/datamaster-collector-biz/src/main/java/com/datamaster/module/collector/utils/ds/component/ShellComponent.java`
- `datamaster-collector/datamaster-collector-biz/src/main/java/com/datamaster/module/collector/utils/ds/component/PythonComponent.java`

这些组件通过 `ComponentRegistry` 注册，并由 `TaskConverter` 转换成 DolphinScheduler 所需的任务参数。

## 和数据集成的关系

当前数据开发和数据集成的关系是：

- 后台共用 collector ETL 任务体系。
- 数据开发通过 `type=3` 区分。
- 数据集成通常通过 `type=1` 区分。
- 发布、卸载、调度、执行、实例日志等能力共用同一套后台服务。
- 数据集成页面提供输入、转换、输出等可视化链路组件。
- 数据开发页面偏 SQL 编辑、模板、任务属性配置和执行。

## 当前收敛方向

数据集成负责“采集 + 转换 + 落库”的完整链路，数据开发负责独立 SQL/存储过程/Shell/Python 执行，两者边界保持清晰。
