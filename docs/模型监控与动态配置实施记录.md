# 数据分析命名、模型监控及动态供应商配置

## 页面入口

服务监控页新增「模型调用监控与配置」按钮；直接路由 `/monitor/model-gateway`。

页面是统计表格及管理员配置表单，不是新建BI看板。可按近1/7/30天、供应商和模型查看当前空间调用次数、状态、平均耗时和Token用量覆盖。未知用量不当作零成本；DB-GPT（界面称数据分析服务）外层请求不代表内部模型调用次数。

前端主要入口、路由和文本归一化已将「决策智能体 / DB-GPT」改称「数据分析」，内部兼容API、类名和协议保持不变。数据库动态菜单标题由新迁移精确更新，不批量改其他业务名称。

## 动态模型配置

同页「当前空间模型配置」支持新增/编辑供应商、模型、兼容API地址和API Token，启用后设为默认。

- 目前支持现有OpenAI-compatible协议，不代表支持所有厂商原生协议。
- 每空间最多一个默认模型，新配置默认inactive；后续新模型客户端读取数据库默认配置，在途请求不切换。
- 平台Data Agent、指标数据分析（包括其复用模型工厂的调用方）、本体/Skill文本生成网关接入ActiveModelResolver。
- 默认配置解析使用可信当前调用空间；无空间或该空间无默认模型时沿用部署的ai.skill-model。没有导入/覆盖原百炼API Token。
- 现有默认供应商属性ai.skill-model.provider=BAILIAN，db-gpt.provider=BAILIAN，基于当前部署为阿里百炼的运维声明，不按模型名字推断。
- 数据库配置表未部署、密钥错误或解密失败会报错，不静默切回另一个供应商；因此必须先迁移再部署启用。

## Token安全

仅具有ai:model-config:list/add/edit/remove相应权限且为平台管理员/系统运维者可管理；普通问数用户不能填写任意端点或密钥。可用模型摘要不返回地址或Token。

Token使用独立AES-GCM加密，服务端必须提供 `ai.model-profiles.encryption-key`，可通过环境变量 `AI_MODEL_PROFILES_ENCRYPTION_KEY` 提供Base64编码的16/24/32字节AES密钥。无内置默认密钥；缺密钥不能保存或解析动态Token。不自动生成或提交密钥。轮换前需妥善保管原密钥并迁移密文。

列表只返回hasApiKey；编辑Token留空保持原值，弹窗关闭清空输入，不放localStorage。保存与激活不自动探测新地址，但后续真实模型调用会向该地址发送业务上下文，因此管理员应审核端点与出站网络策略。

## 数据分析服务（DB-GPT）边界

平台动态模型配置不自动改变DB-GPT内部模型部署和凭据。它独立部署，需在其配置同步调整API/Token；平台只统计外层调用。db-gpt.provider是实际供应商的运维声明，切换其内部配置时须同步声明，否则统计标签不准确。没有把用户填写的Token发送给DB-GPT。
