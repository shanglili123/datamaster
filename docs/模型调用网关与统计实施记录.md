# 模型调用准入与 DB-GPT 统计

## 复用与接入

保留已有IAiModelGatewayService/AiModelGatewayServiceImpl（文本生成协议入口），在其下补AiInvocationGateway统一准入、元数据记录。不是新增独立HTTP模型代理，不改变现有模型提供方或API密钥配置。

已接入边界：

- 本体/Skill经旧complete调用：MODEL / TEXT_COMPLETION。
- LangChain4j Data Agent：MODEL / DATA_AGENT，每次模型generate/chat单独计量，工具运行时不占模型槽位。
- 指标问数及其调用方：MODEL / ASK_METRIC，保留当前AskMetricAgentService其他改动。
- DB-GPT客户端chatCompletion、chatCompletionV1、chatCompletionV1Stream、chatCompletionStream：DBGPT / 对应方法名，AOP在请求前准入，finally释放。数据源/知识库管理HTTP不计为模型调用。

一次begin计一条逻辑调用，包含该客户端内部重试；不是每条HTTP尝试都计一次。Agent多轮会计多次generate，而不是一个问题只计一次。DB-GPT一个外层请求可能内部调用多次模型，平台只记录外层请求，**不能将DBGPT次数当作内部模型调用数**。

## 配置与并发

```yaml
ai:
  invocation:
    max-concurrent: 8
    dbgpt-max-concurrent: 4
```

当前是两个独立、单JVM、非阻塞信号量；满额立即拒绝并记REJECTED，不无限排队。未提供分布式配额、RPM/TPM限速、按空间公平调度或熔断。多实例总并发相加，共享账号配额不会因应用扩容自动增加。

客户端重试保留原行为，重试期间保持同一个准入槽位。DB-GPT旧react-agent readTimeout=0尚未更改，卡住连接会持续占位，需下一步配置有限超时和真实取消。

## 持久化和接口

新增迁移：`sql/update_20261028_ai_model_invocation.sql`，未执行；不会在启动时自动建表。

表 `ai_model_invocation` 保存：kind/scene/model、真实用户/空间/操作ID（上下文可得时）、streaming、SUCCESS/FAILURE/REJECTED、耗时、实测input/output/total tokens、usage_known、有限错误分类/HTTP状态。

不保存提示词、返回正文、URL、密钥或原始异常。其他历史审计/会话的正文持久化行为不由此统计表替代，详见已有入库边界说明。

GET `/ai/model-gateway/stats?spaceId=...&spaceCode=...&days=7`

- 要求ai:ask-data:query及当前空间成员校验；days限定1..30。
- 仅聚合指定已授权空间，按kind/scene/model/status分组，含次数、累计/平均耗时、实测Token合计、已知与未知用量计数。
- 不暴露跨空间的活动调用计数；processCapacity只返回本机配置额度。
- 未能获取空间的内部生成调用仍记录null空间，不被某个租户统计页擅自归属。DB-GPT问数同步/报告及异步流已显式传递用户与空间上下文。

写统计是best-effort：表未迁移或数据库失败不覆盖已有模型调用结果，内部persistenceFailures累计失败并固定文案告警。因此在执行迁移前不能宣称记录已入库，统计接口会提示不可用。没有新增前端仪表盘或自动清理任务。

## Token口径

- LangChain4j取Response.tokenUsage实测值；旧网关与DB-GPT只提取响应顶层usage的prompt_tokens/completion_tokens或input_tokens/output_tokens。
- DB-GPT原始SSE帧在解析时读取usage；重复累计usage帧取最后值，不求和；usage-only帧不混入回答正文。
- 未报告或格式非法为NULL/unknown，不以文本长度估算，不把未知当0。
- 流被旧协议提前结束、上游未提供usage或DB-GPT只给部分用量时，不能得到完整计费用量。总量只有input/output都可得时才标known。
- 失败的LangChain4j内部重试可能产生未报告消耗；当前结果Token不代表完整账单成本，未接供应商账单核对。
