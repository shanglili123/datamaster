## 已实现

- 空间列表“功能流程”对话框，首版4个模板：元数据直用、资产、质量、资产+质量；不将ODS/DWD/DWS/ADS或数据开发工具作为前置门禁。
- 保存草稿不影响现行规则，revision防覆盖；发布锁定配置并递增不可复用版本，保存发布历史。图定义支持固定能力DAG，校验循环/悬空/重复/绕过路径，所有已配置门禁必须约束API与分析。
- 新跨模块 `ISpaceFlowApi`；通过已发布节点判断资产和质量前置。空间管理员（且具备原空间编辑权限）或平台管理员管理，仍检查真实空间关系。
- 通用资产治理在原开关之前检查空间流程。资产前置时要求唯一、已发布/有效资产和原表/字段授权，不允许退元数据，也不因全局off跳过。
- 质量按当前空间、数据源、精确表名、流程版本保存可用性依据。人工确认须原因；检查依据必须当前空间同表成功完成且零问题的日志；支持撤销及追加事件留痕。原检查不合格状态不被改写，不授予资产权限。
- API发布前增加检查（异常不被旧发布catch吞掉），测试和实际查询经原治理入口继续检查。严格空间对自定义SQL暂时拒绝，因尚不能可靠核验全部参与表；普通表映射API可使用。
- 远端探索问数无法证明实际读取全部表，严格空间暂拒绝，提示使用正式指标受控路径；未配置空间保留原行为。正式指标仍经现有来源治理检查。
- 新增 `SpaceFlowRulesTest`：轻量/严格链、绕过、循环、断开、重复和仓层节点拒绝；测试未运行。

## 流程配置与发布主线继续（2026-11-11，未运行验收）

本轮回到P0流程本身，不扩展质量整改业务，不执行质量检查，也不将P1指标增强标为完成。

- **草稿/生效分离**：页面分别显示当前已发布规则与待保存草稿。未加载成功时不宣称未配置；加载失败不能保存/发布。保留服务端已保存的完整节点及连线，不再仅凭节点选中模板后静默改写连线；非当前模板定义明确提示，用户选择模板才替换草稿。
- **草稿校验**：新增 `POST /tax/space-flow/validate`，沿用当前管理员及成员检查，复用已有后端DAG/防旁路校验，只校验客户端候选定义，不保存、不发布、不执行任务。
- **发布预览**：新增 `POST /tax/space-flow/publish-preview`。只读取服务端已保存且revision匹配的草稿，在同一只读快照中比较现行规则，返回新增/移除前置要求、连线变更、下一版本及旧确认不继承提示。忽略请求附带的候选定义，发布仍锁行并校验相同revision，避免预览后旧草稿覆盖新规则。
- **确认交互**：发布前显示前后规则，降低门禁、相同定义再次发版及旧依据换版失效均显式告知。预览不执行任务；正式发布也只更新规则，不启动采集、质量、开发或指标查询。
- **发布历史与恢复**：新增 `GET /tax/space-flow/versions`，按空间分页、版本倒序，显示规则、发布人ID及时间。历史版本可复制为本地草稿（覆盖前确认），恢复仍需保存、预览并发新版本，不覆盖线上、不复用历史版本号。切换空间/重载时清空历史和预览，并隔离迟到响应。
- **页面主次**：原质量节点维护收起在可选折叠区域，主界面先呈现流程配置/校验/预览/版本；本轮没有新增质量业务能力。
- **影响统计边界**：预览只保证规则差异，明确 `consumerImpactKnown=false` 并说明尚未统计全部存量API/指标/依赖来源；不能将未知显示成零影响。自由画布与真实消费影响清单仍待实施。
- **测试与迁移**：扩展 `SpaceFlowRulesTest`（要求增删/顺序与连线变化），新增 `SpaceFlowPublicationTest`（保存草稿预览、过期revision、发布锁、分页历史及空间权限）。未运行任何测试/编译/lint/构建/浏览器联调/迁移，本轮无新增数据库结构或迁移。
