# 空间流程与指标增强首版交付记录

日期：2026-11-11。**代码已落盘，未运行验收；不是生产可用声明。** 本轮连续推进P0与P1，不进入P2质量整改闭环，不启动任何数据任务。

## 一、空间流程（P0）

### 已落盘

- 四模板、固定能力节点的DAG编辑器：节点拖动布局、增删资产/质量节点、增删连线；布局仅展示，不改变执行语义。元数据、API、分析固定保留，不提供任意脚本或替代DS编排。
- 后端复用防循环/断开/重复/绕过校验；保存草稿不生效，revision防覆盖，发布锁行并新建不可复用版本。
- 当前生效与草稿分开显示，草稿校验、发布差异预览、降低要求提示、发布历史、历史复制为草稿（需重新保存并发新版本）。发布不运行采集、质量、开发或指标查询。
- 新增 `SpaceFlowImpactProvider` 接口，服务/本体各自提供API登记与正式指标发布快照清单。预览及 `/consumer-impacts` 支持分页，限定真实空间；正式指标不使用草稿名称/来源，缺失快照或空间不一致明确标未知。
- 清单不输出SQL、连接配置、凭据或源数据。新增 `SpaceFlowReadinessService` 按**已保存草稿/下一发布版本**只读核对资产是否唯一登记、启用发布、空间有效授权及新版本质量依据；返回缺项码、下一步与尚需核验项。严格脚本来源未解析、空间不一致单独提示，未知配置不猜测来源。没有缺项仍标“待消费核验”，不返回放行许可；模块未部署时total为null而非0，外部依赖仍使 `consumerImpactKnown=false`。
- API显式发布、保存/更新直接启用、调试与映射实际消费使用共享来源guard；服务端锁定已有归属，缺空间拒绝；FORM重生成，严格空间SCRIPT/无法核验远端探索保守拒绝。普通本体编辑禁止改空间，避免正式指标静默换政策。

### 边界

- 编辑器是现有五个能力节点的自由连线，不是无限节点工作流引擎。布局现随draft/published JSON保存，坐标后端限界；布局变化不计为准入规则变化，旧定义无layout仍可读取。
- 已登记API/指标是真实清单，不是完整全平台血缘；外部调用、无归属历史数据、脚本多表不能声称已完全覆盖。未证明全部来源的严格入口拒绝，而非只检查主表后放行。
- API实际请求先按映射ID重读当前记录，停用/删除/失效或路由版本变更拒绝使用旧缓存；文件/转发类严格空间拒绝。SQL解析新增可信空间上下文，严格空间拒绝无法核验全部来源的脚本解析，轻量路径仅允许SELECT。导入更新/新增复用归属及启用检查，删除先逐记录校验空间；可见服务列表/详情/调用接口须明确当前成员空间，不能用空scope获得跨空间服务。
- 映射消息事务提交后发送（回滚不发送），异步按当前已提交状态对账而非旧命令，路由变更清理旧映射；注册/撤销校验API归属，旧撤销不能移除其他API，默认版本不被其他注册修改。失败日志可见，显式发布/注销不再吞异常假成功。仍无持久outbox/自动重试，不能宣称分布式原子发布。
- 对象浏览、关系跳转和对象血缘统一从概念所属本体取得可信空间；请求改归属拒绝，关系源/目标同本体核验。对象与关系表的实际候选列全部参与治理，严格来源拿不到列时不回退SELECT *；默认投影限定为已核验列。血缘权限摘要核验失败不显示默认放行；拒绝或仅部分字段授权时不读取/返回完整动作快照。API隐藏字段/结果脱敏异常拒绝返回原始数据。
- 自动质量事件、资产/质量结果页维护入口及P2整改业务未扩展。

## 二、指标与分析（P1）

### M03 轻量来源

- 新 `MetricSqlDialect` 闭集支持Doris/MySQL/PostgreSQL：白名单引用、库/schema、LIMIT、日/月/年表达式。PostgreSQL必须明确schema，查询连接数据库与已发布数据库一致、schema与注册连接一致，不改连接库名来迁就快照。
- 新发布快照记录 `sourceMode=SPACE_FLOW`，按当前空间已发布流程执行。未配置及轻量空间可用本空间真实元数据，不强制ADS命名或资产；资产要求一旦配置仍严格检查，质量要求仍由共同治理入口执行，不回退。
- 轻量来源要求有效的数据源空间关联、唯一登记的有效库/schema/表及参与字段，表/列安全分级不为空时保守拒绝，要求走严格授权；全局strict资产规则仍保留。当前绑定须与发布快照一致。
- **不修改旧发布快照**：无SPACE_FLOW标志的历史版本保留Doris ADS及严格资产约束。希望使用新路径需明确重新发布，不能静默放宽。
- 部署执行开关、批准binding名单、只读账号名单、JDBC只读、并发、超时全部保留；新增方言不表示真实驱动已兼容验证，默认仍不可执行。

### M04 时间分析

- NONE/DAY/MONTH/YEAR在源库聚合，保持 `[start,end)`。发布定义支持成对 `sourceTimeOffset/businessTimeOffset`（±HH:mm，最大±14:00），业务输入边界转换为来源时刻，桶表达式按固定分钟差平移；未配置保留原来源本地时间。**不支持IANA区域夏令时自动转换**，不猜测来源偏移；date无时刻信息不得配置不等偏移。
- 页面快捷填今天、近7日、本月至今、上个完整月；有发布业务偏移时按该日期填入，未配置沿用浏览器日期并要求核对，不自动查询。固定与额外时间属性过滤仍按物理字段口径，页面与响应明确说明。
- `/compare` 两期总量、完整维度分组及时间桶：上一等长区间、上一月、上一年、自定义基期。日/月/年桶要求业务零点完整边界、两期桶数一致（1..500），按桶序号对齐并返回对应基期桶，**不是业务工作日等价推断**；不等长日桶/部分桶拒绝，月底/闰日总量日历平移仍列出实际区间。
- 非第一页、分组/桶独立TopN拒绝。维度筛选两期原样保留，时间属性过滤拒绝以免锁死基期；固定口径保留。
- 两期分组按后端生成的维度键对齐，null组单独保留；单期缺失不补零，任一期截断拒绝计算变化，重复组拒绝覆盖。响应增加columns/rows/grouped及本期区间，原总量difference/changePercent兼容保留。
- 同一明确发布版本分别查询两期，不从TopN推算总量。差值/百分比BigDecimal，基期零或缺失不算百分比；负基期变化率分母用绝对值并明示。两次查询不是源库同一事务快照。

### M05 排序/TopN/分页/下钻

- sortBy仅固定metric_value、已选d_<id>或time_bucket，方向ASC/DESC；完整分组作为稳定并列顺序，聚合后排序再LIMIT。旧条件没有排序继续旧序。
- pageNum=1..1000、limit=1..500，服务端绑定OFFSET；limit+1判下一页，不估算total。第二页及以后truncated始终标记非完整，hasMore独立；页间不冻结源数据。
- 页面点击分组行转成EQ/IS_NULL过滤并排除已筛定维度选择下一级，最多20层条件历史，可返回上一级。时间桶按业务日历算边界并与原区间取交集，保留部分桶原始起止、不跨浏览器时区；只修改条件，需手动执行。切指标/版本/保存分析时清空下钻历史。
- 新 `requireComplete`有界完整模式与“完整趋势”按钮：单序列不分维度、按时间桶升序、最多500桶；源查询前核验期望日历桶数，返回后对缺失桶补显式null而不是0，使折线断开。超限只返回明确错误，不返回部分趋势，不逐页拼接假快照。无源库无限全量读取或模型全量灌入。
- 普通分页仍可浏览更多分组，但任何当前页/TopN不能宣称完整趋势；布局渲染与真实驱动行为仍待验证。

### M06 多指标与临时派生

- `/multi-query` 后端2..4个正式指标，页面首版选两指标明确版本。要求同本体/概念/绑定/粒度/时间属性/物理来源，共享属性映射一致，用户分组/时间/筛选相同；每指标固定口径保留并显示版本。
- 不支持跨库JOIN；先授权全部再依次查询。只接受默认或时间桶升序的第一页并要求各结果完整未截断，再按分组对齐，缺失不补零。
- NONE/RATIO/DIFFERENCE/SUM白名单临时运算，二元运算须两个指标，相加/差值单位一致；SUM还要求同类SUM/COUNT，不直接相加AVG/COUNT_DISTINCT。分母零返回缺失，BigDecimal避免浮点丢失。单位不做自动换算，不猜测业务可比性。
- 正式派生新增 `derivedOperation/secondaryAggregation/secondaryValuePropertyId/primaryUnit/secondaryUnit` 定义，复用已有指标草稿、校验、发布不可变快照、历史版本、停用及历史复制为草稿生命周期。历史恢复须当前revision与身份一致，不改生效版本/状态、不复制旧来源授权；重新发布再校验当前绑定。限定同表同筛选的两个聚合后RATIO/DIFFERENCE/SUM，不是逐行计算或跨指标依赖树。两项物理列均参与来源权限检查；分母0用NULLIF返回缺失，比率同单位结果单位1，否则主单位/次单位，不自动乘100或单位换算。
- 正式派生相加仅同类SUM/COUNT，结果不可再被临时相加当可加指标；COUNT_DISTINCT/AVG不跨桶再汇总，不把分组去重之和当总去重。任意表达式、其他指标版本依赖图、跨来源公式仍不支持。

### M07 展示

- 新 `DeclarativeChartRenderer` 复用于正式指标与报告的线/柱图，报告原饼图保留原路径；不加载任意图表脚本或执行配置。
- 单一分组/时间桶的单序列条形/折线，精确表格保留，null断线不补零，显示当前页/TopN边界；鼠标/键盘聚焦可查看精确值与竖向定位线，不以双轴混单位。
- 绘图仅近似，精确值保留字符串及提示；超过500项或超过JS安全绘图幅度时退回表格，不能悄悄截掉再称完整。单序列用继承文字色及标签，不引入未经验证的分类色板；暗色随主题文字/Canvas对比，原始表格始终可读。
- 未渲染/截图，布局、悬浮、键盘及主题效果需本地验收。
