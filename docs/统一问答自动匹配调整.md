# 统一问答自动匹配调整（历史局部方案，已被替代）

更新：2026-11-17。**本文原有“独立指标Agent优先、无匹配后转DB-GPT”的方案已作废，不作为后续实现依据。**

最新已确认设计见 [统一问数Agent与能力编排实施方案](统一问数Agent与能力编排实施方案.md)。计划2026-11-18在用户续接后实施；今天仅改文档。

## 撤回的设计结论

- 不再用关键词把普通业务问题锁进指标Agent、探索问答、决策、报告的固定分支。
- 不保留用户面对的专门指标问答Agent；只保留可复用指标定义、发布版本、受控查询和工具能力。
- 不要求完整指标目录为空才允许普通问答。指标不适用或必要条件不足时可不用指标，继续普通问答并可在最后引导。
- 不因有时间属性强制所有问答补日期，也不强制所有无日期问题都统计全部；参数由目标、定义和可信上下文决定，范围需说明。
- 不把Skill、报告模板、本体或某类来源做成每次必须满足的门槛；权限和治理仍必检。
- 不继续以不断增长的场景提示词、测试业务关键词、固定引导语修补执行机制。

## 可保留的局部修复（不等于方案完成）

- 名称误传code的输入处理、同本体有界候选检索及发布快照身份核验。
- 无本轮查询证据禁止输出历史统计数字，失败/待补充不能全绿。
- 可选时间参数的空字符串归一化、成对有效性检查、固定口径和权限保留。
- 脱敏错误诊断与调用关联，不以通用错误吞掉全部原因。

这些源码与测试曾分批修改，运行覆盖不一致；不得把本文当构建或真实页面验收通过记录。后续重构应检查工作区，不覆盖其他人修改，不直接全量回退。

## 新的统一行为

一个问数Agent语义规划，多轮选择指标/Skill/本体/资产/元数据/DB-GPT及分析、报告、决策、动作能力；优先选择适用且准确来源，不强制固定次序。报告可使用已有查询与分析结果，有模板按模板，无模板自定义。决策与动作可同会话衔接，但真实提交保留确认审批。公开执行活动灰色流式显示，最后基于证据生成答案及可选引导，不能展示原始思维链或伪造执行。
